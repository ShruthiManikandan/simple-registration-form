# Simple Registration Form

## 📌 Project Description

This project is a simple and responsive registration form developed using HTML, CSS, and JavaScript. It allows users to enter their Name, Email, and Password, with real-time form validation to ensure that all inputs meet the required conditions before submission.

## ✨ Features

* **Name Validation:** Checks whether the Name field is empty and displays an error message if it is.
* **Email Validation:** Validates the email address format and displays an error message if the format is incorrect.
* **Password Validation:** Ensures that the password contains a minimum of 6 characters.
* **Real-Time Validation:** Validates user inputs dynamically using JavaScript.
* **Submit Button Control:** Keeps the submit button disabled until all fields are correctly validated.
* **Error Messages:** Displays appropriate error messages for invalid inputs.

## 🛠️ Technologies Used

* **HTML5** – To structure the registration form.
* **CSS3** – To style the form and create a user-friendly interface.
* **JavaScript** – To implement real-time validation and control form submission.

## ⚙️ How It Works

1. The user enters their Name, Email, and Password.
2. JavaScript validates each field based on the specified requirements.
3. Error messages appear when the entered information is invalid.
4. The submit button remains disabled until all fields pass validation.
5. Once all fields are valid, the submit button becomes enabled, allowing the user to submit the form.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in any web browser.
4. Enter the required details and test the form validation.

## 🎯 Project Objective

The main objective of this project is to understand form validation using JavaScript, handle user input, display validation messages, and improve the user experience by preventing invalid form submissions.
